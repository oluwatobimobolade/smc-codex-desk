## Objective

Explain why the causally supported HYPEUSDT supply near 59.7–60.4 disappeared from the native chart, preserve the original active-entry safeguards, and add a governed way for deterministic evidence and the AI seat to retain material superseded context without inventing trade authority.

## Confirmed cause

The original rejection rules were individually correct:

- direction-mismatched POIs do not become active entries;
- a later opposing external break supersedes an older lineage for current directional control;
- a broad geometric base that is not the nearest traced departure origin is not promoted as a causal OB.

The defect was downstream. Native storyboard selection, a silent four-object slice, and post-render cleanup treated “not the active entry” as “do not display.” That erased accepted historical structure, causal supply, and its imbalance from the professional chart even though those objects remained material context.

## Repair

- Added a deterministic context authority that is separate from active-entry authority.
- A context cluster is eligible only when its structure break passed V3 admission and its OB/FVG has sealed causal lineage.
- A lower-timeframe refinement may be displayed only when it is an admitted causal origin inside the parent zone and causal window.
- The AI may request a visibility exception only for an already prequalified, hash-bound requirement and must return the exact object ID plus a rationale and explicit authority acknowledgements.
- The exception cannot create or move a zone, change bias, choose an active POI, or produce entry, stop, target, RR, trade box, paper order, or live order.
- Evidence windows expand only as far as a required anchor, retain the newest candle, and fail closed beyond a 720-row ceiling.
- Native rendering records requested, required, rendered, off-window, unsupported, deduplicated, and budget-omitted IDs. Required context cannot be silently truncated or removed by the visual critic.
- Bearish OB/FVG context uses trader-readable red/amber styling, dashed context borders, and explicit `(context)` labels.
