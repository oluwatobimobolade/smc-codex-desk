# WP-0041B AI Annotation Render Loop

**Status:** `VALIDATED_LOCAL_OBSERVE_ONLY`

WP-0041B closes the missing loop between AI semantic annotation selection and
the final chart image. The AI selects certified semantic object IDs; a
deterministic resolver supplies price and time geometry; a sparse renderer
draws the chart; pixel QA proves that every selected object is visible; and the
visual critic runs only after the rendered images exist.

This package creates no predictive, paper-trading, or live-execution authority.
