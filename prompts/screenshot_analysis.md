# Screenshot Analysis Prompt

Analyze this chart using Smart Money Concepts.

## Context

- Symbol: `[SYMBOL]`
- Timeframe: `[TIMEFRAME]`
- My bias: `[OPTIONAL]`
- My notes: `[OPTIONAL]`

## Tasks

- Identify the likely higher-timeframe bias if it can be inferred
- Mark the dealing range, external liquidity, internal liquidity, equal highs or lows, BOS, CHoCH, FVGs, order blocks, session highs or lows, premium or discount, and likely sweep path
- Distinguish confirmed observations from hypotheses
- Annotate the chart with my view in blue and your view in red

## Output

- concise written thesis
- annotated PNG
- JSON trade plan

## Constraint

Use only what is visible on the chart and clearly label uncertainty where needed.
