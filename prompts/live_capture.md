# Live Capture Prompt

Open the trusted chart source, capture the current 4H and 15m views for the requested symbol, run both through the SMC analysis pipeline, and generate a combined report.

## Deliverables

- higher-timeframe bias
- lower-timeframe execution setup
- annotated charts
- entry zone
- invalidation
- targets
- JSON trade plan

## Constraint

Do not place trades. Analysis only.
